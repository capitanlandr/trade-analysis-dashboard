# Dashboard Data Files

This directory contains static JSON files that power the dashboard. These files are **generated by the Python pipeline** and committed to the repository for static site deployment.

## Architecture

The dashboard uses a **static site** architecture:
- JSON files are pre-generated by the pipeline
- No backend API server required
- Files are committed to Git and deployed to Vercel
- Updates trigger automatic Vercel redeployment

## Generating Data

**Full update (recommended):**
```bash
# From project root
python3 update_dashboard.py
```

This command:
1. Detects current week from Sleeper API
2. Fetches all trade, standings, and waiver data
3. Runs playoff simulations (10,000 scenarios)
4. Calculates draft order projections
5. Generates all 7 JSON files in this directory
6. Commits and pushes to GitHub
7. Triggers Vercel deployment

**Individual data generation:**
```bash
# From project root
cd pipeline

# Trade data and manager rankings
python3 scripts/generate_dashboard_json.py

# Waiver wire metrics
python3 scripts/generate_waiver_wire_dashboard_json.py

# Current standings
python3 scripts/fetch_standings.py

# Playoff scenarios
python3 scripts/simulate_playoff_scenarios.py

# Draft order projections
python3 scripts/calculate_progressive_draft_order.py
```

## File Descriptions

### api-trades.json
Trade analysis with valuations and win/loss tracking.

**Schema:**
```typescript
{
  success: boolean;
  data: {
    trades: Array<{
      tradeId: string;
      tradeDate: string;
      teamA: string;
      teamAReceived: string[];
      teamAValueThen: number;
      teamAValueNow: number;
      teamB: string;
      teamBReceived: string[];
      teamBValueThen: number;
      teamBValueNow: number;
      winnerCurrent: string;
      swingMargin: number;
    }>;
  };
}
```

### api-teams.json
Manager statistics and rankings.

**Schema:**
```typescript
{
  success: boolean;
  data: {
    teams: Array<{
      sleeperUsername: string;
      realName: string;
      teamName: string;
      tradeCount: number;
      winRate: number;
      totalValueGained: number;
    }>;
  };
}
```

### api-stats-summary.json
League-wide trade statistics.

**Schema:**
```typescript
{
  success: boolean;
  data: {
    overview: {
      totalTrades: number;
      avgTradeMargin: number;
      mostActiveTrader: string;
      biggestWinner: string;
    };
  };
}
```

### api-standings.json
Current week standings with division information.

**Schema:**
```typescript
{
  success: boolean;
  data: {
    current_week: number;
    standings: Array<{
      team_name: string;
      wins: number;
      losses: number;
      ties: number;
      points_for: number;
      points_against: number;
      division: string;
    }>;
  };
}
```

### api-playoff-scenarios.json
Monte Carlo simulation results showing playoff probabilities.

**Schema:**
```typescript
{
  success: boolean;
  data: {
    results: Array<{
      team_name: string;
      playoff_probability: number;
      projected_seed: number;
      seed_min: number;
      seed_max: number;
      division_win_probability: number;
      first_round_bye_probability: number;
      championship_probability: number;
      clinched_playoff: boolean;
      clinched_division: boolean;
      clinched_bye: boolean;
      eliminated: boolean;
    }>;
    metadata: {
      current_week: number;
      num_simulations: number;
      generated_at: string;
    };
  };
}
```

### waiver-wire-page.json
Waiver wire efficiency metrics for each manager.

**Schema:**
```typescript
{
  success: boolean;
  data: {
    managers: Array<{
      manager_name: string;
      hit_rate: number;
      hit_rate_percentile: number;
      churn_index: number;
      churn_percentile: number;
      efficiency_score: number;
      efficiency_percentile: number;
      timing_score: number;
      timing_percentile: number;
      total_adds: number;
      successful_adds: number;
    }>;
    league_averages: {
      hit_rate: number;
      churn_index: number;
      efficiency_score: number;
      timing_score: number;
    };
  };
}
```

### api-draft-order.json
Progressive 2026 draft order projections by week.

**Schema:**
```typescript
{
  success: boolean;
  data: {
    current_week: number;
    projections: Array<{
      week: number;
      draft_order: Array<{
        pick: number;
        team_name: string;
        owner: string;
        wins: number;
        losses: number;
        points_for: number;
      }>;
    }>;
    current_ownership: Array<{
      original_team: string;
      current_owner: string;
      pick_number: number;
    }>;
  };
}
```

## Important Notes

### File Management

✅ **These files ARE committed to Git** - Required for static site deployment

✅ **Safe to regenerate** - Running the pipeline will overwrite these files with fresh data

⚠️ **Do not manually edit** - Changes will be overwritten on next pipeline run

### Data Freshness

**Update triggers:**
- After trades are processed in Sleeper
- After waivers clear (usually Wednesday morning)
- After weekly games complete
- When you want updated playoff scenarios

**Update frequency:**
- **Automated**: Daily at 9 AM EST via GitHub Actions
- **Manual**: Run `python3 update_dashboard.py` anytime

### Deployment Flow

```
Pipeline generates JSON files
    ↓
Files committed to Git
    ↓
Push to GitHub
    ↓
Vercel detects changes
    ↓
Automatic deployment
    ↓
Dashboard updated (2-3 minutes)
```

## Validation

Check if files are valid JSON:

```bash
cd dashboard/frontend/public
for f in api-*.json; do
  echo "=== $f ==="
  jq . "$f" > /dev/null && echo "✓ Valid JSON" || echo "✗ Invalid JSON"
done
```

## Troubleshooting

**Files are missing:**
```bash
python3 update_dashboard.py
```

**Files have old data:**
```bash
# Check timestamps
ls -lh dashboard/frontend/public/api-*.json

# Regenerate
python3 update_dashboard.py
```

**Invalid JSON errors:**
```bash
# Validate all files
cd dashboard/frontend/public
for f in api-*.json; do jq . "$f" > /dev/null || echo "Invalid: $f"; done

# Fix by regenerating
cd ../../..
python3 update_dashboard.py
```
