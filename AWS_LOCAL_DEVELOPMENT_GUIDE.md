# AWS Local Development & Testing Guide

## Your Question: How to Test AWS Services Locally?

**Short Answer:** You can test AWS Lambda, DynamoDB, API Gateway, etc. **locally on your laptop** before deploying!

**Two main approaches:**
1. **AWS SAM (Serverless Application Model)** - Official AWS tool
2. **LocalStack** - Community tool that emulates AWS locally

---

## Current Architecture (Static)

```
Frontend (React) → JSON files (in S3) → No backend
```

**Pros:** Simple, fast, cheap ($0.03/month)
**Cons:** No dynamic data, requires rebuilding to update

---

## Target Architecture (Dynamic Backend)

```
Frontend (React)
    ↓ (HTTPS API calls)
API Gateway (AWS endpoint)
    ↓ (triggers)
Lambda Function (Python/Node.js code)
    ↓ (reads/writes)
DynamoDB OR S3 (data storage)
```

**Pros:** Dynamic data, real-time updates, scalable
**Cons:** More complex, slightly higher cost (~$0.10-0.50/month)

## Option 1: AWS SAM (Recommended for Learning AWS)

### What is AWS SAM?

**AWS Serverless Application Model** - Official AWS tool for building serverless apps

**What it does:**
- Runs Lambda functions locally on your laptop
- Emulates API Gateway locally
- Tests with DynamoDB Local
- Deploy to AWS when ready

### Installation

```bash
# Install AWS SAM CLI
brew install aws-sam-cli

# Verify installation
sam --version
```

### Example: Add Dynamic API to Your Dashboard

**1. Create SAM project structure:**
```bash
cd /Users/lndahayo/Documents/Commish\ Tiers/trade-analysis-dashboard-clean
mkdir backend-api
cd backend-api

# Initialize SAM app
sam init
# Choose: AWS Quick Start Templates
# Choose: python3.11 or nodejs18.x
# Choose: Hello World Example
```

**2. Your backend structure:**
```
backend-api/
├── template.yaml        # AWS infrastructure definition
├── src/
│   ├── get_trades/      # Lambda function
│   │   └── app.py       # Your Python code
│   └── get_standings/
│       └── app.py
└── tests/
```

**3. Example Lambda function (Python):**
```python
# backend-api/src/get_trades/app.py
import json
import boto3

def lambda_handler(event, context):
    # Connect to DynamoDB
    dynamodb = boto3.resource('dynamodb')
    table = dynamodb.Table('fantasy-trades')
    
    # Query data
    response = table.scan()
    trades = response['Items']
    
    return {
        'statusCode': 200,
        'headers': {
            'Access-Control-Allow-Origin': '*',
            'Content-Type': 'application/json'
        },
        'body': json.dumps({
            'trades': trades
        })
    }
```

**4. Test locally:**
```bash
# Start local API server
sam local start-api

# Your API runs at:
# http://localhost:3000

# Test endpoints:
curl http://localhost:3000/trades
curl http://localhost:3000/standings
```

**5. Update your frontend to use local API:**
```typescript
// dashboard/frontend/src/services/api.ts
const API_BASE = process.env.NODE_ENV === 'development' 
  ? 'http://localhost:3000'  // Local SAM
  : 'https://your-api-gateway-url.amazonaws.com';  // Production AWS

export const fetchTrades = async () => {
  const response = await fetch(`${API_BASE}/trades`);
  return response.json();
};
```

**6. Deploy to AWS when ready:**
```bash
sam build
sam deploy --guided
# Creates: API Gateway, Lambda, DynamoDB automatically!
```

## Option 2: LocalStack (Emulates Full AWS Locally)

### What is LocalStack?

**Community tool** that runs a complete AWS environment on your laptop

**What it emulates:**
- S3, DynamoDB, Lambda, API Gateway
- CloudFormation, SNS, SQS, etc.
- Almost all AWS services!

### Installation

```bash
# Using Docker
brew install localstack
brew install awscli-local  # Wrapper for AWS CLI

# Start LocalStack
localstack start

# Now AWS services run locally:
# S3: http://localhost:4566
# DynamoDB: http://localhost:4566
# Lambda: http://localhost:4566
```

### Example: Test DynamoDB Locally

```bash
# Create table locally
awslocal dynamodb create-table \
  --table-name fantasy-trades \
  --attribute-definitions AttributeName=trade_id,AttributeType=S \
  --key-schema AttributeName=trade_id,KeyType=HASH \
  --billing-mode PAY_PER_REQUEST

# Put item
awslocal dynamodb put-item \
  --table-name fantasy-trades \
  --item '{"trade_id": {"S": "trade1"}, "value": {"N": "1000"}}'

# Query locally
awslocal dynamodb scan --table-name fantasy-trades
```

**Pros:**
- Test everything AWS without deploying
- No AWS costs during development
- Full AWS API compatibility

**Cons:**
- Requires Docker
- More complex setup
- Not as "official" as SAM

## Example: Adding a Dynamic "Get Latest Trades" API

### 1. Create Lambda Function (Local)

**backend-api/src/get_trades/app.py:**
```python
import json
import requests
from datetime import datetime

def lambda_handler(event, context):
    # Fetch from Sleeper API (real-time!)
    league_id = "1312166810505719808"
    response = requests.get(f"https://api.sleeper.app/v1/league/{league_id}/transactions/1")
    trades = response.json()
    
    return {
        'statusCode': 200,
        'headers': {
            'Access-Control-Allow-Origin': '*',
        },
        'body': json.dumps({
            'trades': trades,
            'timestamp': datetime.now().isoformat()
        })
    }
```

### 2. Test Locally

```bash
# Start local API
sam local start-api

# Test in browser or curl
curl http://localhost:3000/api/trades
```

### 3. Update Frontend

```typescript
// Point to local API during development
const API_URL = import.meta.env.DEV 
  ? 'http://localhost:3000/api'  // Local
  : 'https://your-api.execute-api.us-east-1.amazonaws.com/api';  // AWS
```

### 4. Deploy to AWS

```bash
sam deploy --guided
# Creates everything automatically!
```
